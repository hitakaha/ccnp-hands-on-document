    0. ラボ準備 (開始前に実施)¶

    所要時間

    本編開始前に済ませておきます (本編の 30 分には含みません)。 初期コンフィグを貼り付けるだけで完了します。

    トポロジー¶

    インターフェイス名について

    Gi0/x は CML の IOSv / IOSvL2 を想定した表記です。実機や Cat9000v などでは GigabitEthernet1/0/x などに読み替えてください。

    初期コンフィグ¶

    各デバイスのコンソールで configure terminal に入り、貼り付けます。 (ここにはトピックの設定を含んでいません。トランク、EtherChannel、STP、ルーティングなどは本編で設定します。)

    hostname SW1
no ip domain-lookup
vlan 10
 name USERS
vlan 20
 name SERVERS
vlan 99
 name NATIVE
interface GigabitEthernet0/4
 description to-R1
 switchport mode access
 switchport access vlan 10
interface GigabitEthernet0/5
 description to-R2
 switchport mode access
 switchport access vlan 10
interface GigabitEthernet0/6
 description to-PC1
 switchport mode access
 switchport access vlan 10

    hostname SW2
no ip domain-lookup

vlan 20
 name SERVERS
vlan 99
 name NATIVE

    hostname SW3

    開始前チェック (1 分)¶

    R1# ping 10.0.12.2
R2# ping 10.0.23.2
R2# ping 10.0.24.2
R1# ping 192.168.10.2

    すべて成功すれば準備完了です。

    進行のコツ

    • show 系コマンドは do show ... で設定モードからも実行できます。
    • 時間が足りなくなったら、各トピックの「壊して直す」を省略して次へ進んでください。
    • 3.3.a の NTP は同期に数分かかるため、先に設定して最後に確認します。
